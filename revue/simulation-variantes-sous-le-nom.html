Les variantes sous le nom — ce que tu as décrit

« Quand je clique sur Parcourir le dictionnaire, et que je clique sur un exo, une fois que j’ai cliqué sur le nom principal, il va s’afficher dans “Nom de l’exercice” et proposer automatiquement les variantes en dessous si l’on veut en sélectionner une. »

Rien n’est poussé. L’écran de gauche fait 320 px, avec le vrai CSS et le vrai dictionnaire — clique vraiment : Parcourir → un groupe → un mouvement, et le bloc des variantes apparaît sous le champ.
